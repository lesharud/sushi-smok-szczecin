# Проверка расширения — 14.09.2026

Production build (`npm run build`): успешно. Предварительный рендер главной, 16 категорий, 68 блюд, меню и сервисных страниц выполнен. Файлы всех 48 используемых фотографий каталога существуют.

15 браузерных сценариев Playwright успешно выполнены с повторным запуском исправленных проверок. 13 сценариев прошли в общем запуске, после этого отдельно прошли мобильный touch-flow и исправленный сценарий каталога с дополнительной проверкой reload URL поиска. Не утверждается, что Supabase или реальный канал заказа тестировались.

Проверено:

- Сохранённая главная: диапазон 320–1920 px, галерея, фильтры, fullscreen menu, Tab/Shift+Tab/Escape, возврат фокуса, ссылки, изображения, HTML без JavaScript.
- Каталог: реальные категории/цены, поиск без диакритики, очистка поиска, прямые ссылки, reload поискового URL, страницы блюд и 404.
- Корзина: добавление нескольких порций, +/- и удаление, пересчёт, drawer focus, пустые состояния, localStorage и перезагрузка, отклонение повреждённых записей.
- Checkout: пустые обязательные поля, e-mail/телефон, адрес и неверный индекс доставки, согласие с тестовым режимом, самовывоз/доставка, чек, очистка корзины и история.
- Приватность локального flow: без opt-in история не содержит имя, адрес и e-mail; session-чек восстанавливается в той же вкладке.
- Профиль: opt-in, сохранение, добавление/редактирование/удаление адреса; честная недоступность login/register без конфигурации.
- Мобильный touch-flow 390×844: закреплённое добавление, нижняя корзина, увеличение количества, checkout и успешный тестовый чек.
- Новые страницы: ширины 320, 390, 768, 1440 px, отсутствие horizontal overflow, загрузка фото. Скриншоты desktop/mobile просмотрены, карточка с крупным фото и sheet проверены визуально.
- Axe WCAG 2/2.1 AA: нарушений не найдено в проверенных состояниях главной, overlay, меню, блюда, checkout и профиля.

Использован установленный Chrome с эмуляцией mobile/touch. Физический iPhone, Safari/WebKit и Android-устройство не проверялись. Автоматическая axe-проверка не заменяет полную экспертизу доступности. Реальные заказы, платежи и отправка писем не выполнялись.

Локальный Vite запущен на http://localhost:5174/ (5173 уже занят). Повторный запуск: `npm run dev`.
